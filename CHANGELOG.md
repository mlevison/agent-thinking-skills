# Changelog
Notable changes to this project, following [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-09-18
### Added
- Systems Thinking skill: traces problems upstream, finds the feedback loops holding a situation in place, draws Causal Loop Diagrams.
- Critical Thinking skill: tests claims and decisions against Paul and Elder's Elements of Reasoning and Intellectual Standards, one question at a time.
- Critical Thinking for GenAI skill: eleven probes for testing model-generated output, split out from Critical Thinking.
- Claude Code plugin (`thinking-skills`), listed in the [agile-pain-relief-skills](https://github.com/mlevison/agile-pain-relief-skills) marketplace.
- `npx skills` package support for install across Claude Code, Codex, Cursor, OpenCode, and other agents.
