# Assumptions and Injections
An assumption is the reason an arrow holds. An injection is an action that makes one assumption false, so the arrow no longer holds and the conflict evaporates.

## Surfacing Assumptions
Complete the reading with "because":

> In order to have **[B]**, we must **[D]**, *because*…

Useful prompts when the user stalls:
- "What would have to be true for D to be the only way to get B?"
- "When has B been achieved without D?"
- "What is being taken for granted about the other party, the rules, the time available?"
- For D–D': "Why can't both happen? What makes them mutually exclusive?"

Words like *only*, *always*, *never*, *must* and *can't* mark assumptions worth challenging. Collect several per arrow before judging any.

## Choosing an Arrow
Only one arrow has to break. Where to look depends on who holds the lever:
| Arrow | Who can act on it | Notes |
| --- | --- | --- |
| **B–D** | The initiator | Usually the best first look: the initiator can change their own action without anyone's permission. Gives up the want D, keeps the need B. |
| **C–D'** | The other party | Often where the initiator most wants change, and the hardest arrow for the initiator to break alone. Raise it with the other party rather than for them. |
| **D–D'** | Both, or whoever sets policy | Breaking it often yields the most durable result: a rule stating the conditions under which each action applies, so the conflict does not recur. |
| **A–B, A–C** | Rarely | Challenging these questions whether a need is real. Worth a look when a need seems inherited rather than held. |

A mediator starts wherever both parties agree an assumption looks shaky.

## Testing an Assumption
For each candidate ask:
- Is it true in this situation, or only in general?
- Is it true now, or was it true when the habit formed?
- If it is true, what action could make it false?

An assumption that survives all three is load-bearing. Move to the next one.

## Injections
An injection passes when:
- **Both needs, B and C, are still met.** Meeting both wants is optional.
- **It is an action**, not a hope ("people will understand") or a restatement of D or D'.
- **It invalidates a named assumption.** Trace the link explicitly.

A result that splits the difference between D and D' is a compromise: each side gives up part of its need. Name it and keep looking; a compromise may still be the pragmatic choice, but it should be chosen knowingly.

## Negative Branches
Before calling an injection a solution, ask what it might cause that nobody wants:
> If **[injection]**, then **[effect]**, and then **[undesirable effect]**.

Each reservation gets one of three responses: a supporting action that trims the branch, a different injection, or an explicit decision to accept the risk. Asking the other party for their reservations is also how the injection gains their support.
